## Pendahuluan

Perkembangan teknologi kecerdasan buatan (*Artificial Intelligence* atau AI) membuka peluang baru dalam dunia pendidikan. Salah satu teknologi yang dapat dimanfaatkan oleh guru adalah ChatGPT, sebuah layanan AI dari OpenAI yang mampu membantu menyusun materi, membuat soal, mengembangkan ide, hingga menghasilkan kode program sederhana.

Dengan bantuan ChatGPT, guru dapat mengembangkan media pembelajaran interaktif berbasis web tanpa harus menguasai pemrograman secara mendalam.

Artikel ini akan membahas langkah demi langkah cara membuat media pembelajaran interaktif dengan bantuan ChatGPT, mulai dari menentukan konsep, menyusun perintah (*prompt*), hingga menjalankan dan membagikan hasilnya kepada peserta didik.

## 1. Mengenal OpenAI dan ChatGPT

Sebelum mulai membuat media pembelajaran, ada baiknya kita mengenal terlebih dahulu teknologi yang akan digunakan.

**OpenAI** adalah perusahaan riset dan pengembangan kecerdasan buatan yang mengembangkan berbagai teknologi AI. Salah satu produknya adalah **ChatGPT**, yaitu asisten AI yang dapat memahami instruksi dan membantu pengguna menyelesaikan berbagai pekerjaan melalui percakapan.

Dalam pembuatan media pembelajaran, ChatGPT dapat membantu guru untuk:

- Menyusun konsep dan alur pembelajaran.
- Membuat materi dan soal evaluasi.
- Merancang tampilan media pembelajaran.
- Menulis kode HTML, CSS, dan JavaScript.
- Memperbaiki kesalahan pada kode program.

Dengan demikian, guru dapat memanfaatkan ChatGPT sebagai asisten dalam proses pengembangan media pembelajaran.

## 2. Menyiapkan Peralatan yang Dibutuhkan

Untuk membuat media pembelajaran interaktif dengan bantuan ChatGPT, kita tidak memerlukan peralatan yang rumit.

Beberapa hal yang perlu disiapkan adalah:

1. **Komputer atau laptop** untuk menyusun dan mengembangkan media pembelajaran.
2. **Koneksi internet** untuk mengakses ChatGPT.
3. **Akun ChatGPT** yang dapat digunakan untuk meminta bantuan AI.
4. **Browser** seperti Google Chrome, Mozilla Firefox, atau Microsoft Edge untuk menjalankan media pembelajaran.
5. **Editor teks atau kode**, misalnya Visual Studio Code, untuk menyimpan dan mengedit file HTML.

Jika belum memiliki Visual Studio Code, guru dapat menggunakan editor teks sederhana. Namun, Visual Studio Code lebih disarankan karena memudahkan proses pengeditan kode.

## 3. Menentukan Konsep Media Pembelajaran

Sebelum meminta ChatGPT membuat media pembelajaran, guru perlu menentukan konsep dan tujuan pembelajaran yang ingin dicapai.

Sebagai contoh, kita akan membuat media pembelajaran interaktif dengan konsep berikut:

- **Mata pelajaran:** Ilmu Pengetahuan Alam (IPA).
- **Materi:** Sistem Tata Surya.
- **Jenjang:** Sekolah Menengah Pertama (SMP).
- **Jumlah soal:** 10 soal pilihan ganda.
- **Fitur:** Materi singkat, kuis interaktif, skor otomatis, dan tampilan hasil evaluasi.

Konsep tersebut dapat disesuaikan dengan kebutuhan masing-masing guru.

Semakin jelas konsep yang disampaikan kepada ChatGPT, semakin mudah pula AI membantu menghasilkan media pembelajaran sesuai dengan kebutuhan.

Guru juga perlu menentukan apakah media akan digunakan secara mandiri oleh peserta didik atau dipandu langsung dalam kegiatan pembelajaran di kelas.

## 4. Membuat Prompt untuk ChatGPT

*Prompt* adalah perintah atau instruksi yang diberikan kepada ChatGPT agar menghasilkan jawaban sesuai dengan kebutuhan pengguna.

Dalam membuat media pembelajaran, guru perlu menyampaikan instruksi secara jelas dan terperinci.

Sebagai contoh, kita dapat menggunakan prompt berikut untuk meminta ChatGPT merancang konsep media pembelajaran:

**Contoh Prompt 1:**

> Saya seorang guru IPA SMP. Saya ingin membuat media pembelajaran interaktif berbasis web dengan materi Sistem Tata Surya.
>
> Media pembelajaran ini ditujukan untuk peserta didik SMP dan harus memiliki tampilan yang menarik, sederhana, serta mudah digunakan.
>
> Buatkan rancangan media pembelajaran yang mencakup:
> 1. Halaman pembuka.
> 2. Tujuan pembelajaran.
> 3. Materi singkat tentang Sistem Tata Surya.
> 4. Kuis pilihan ganda sebanyak 10 soal.
> 5. Fitur penilaian otomatis.
> 6. Halaman hasil evaluasi.
>
> Jelaskan juga alur penggunaan media dari awal hingga akhir.

Dari prompt tersebut, ChatGPT akan membantu menyusun rancangan awal media pembelajaran. Guru dapat mempelajari hasilnya, kemudian meminta perubahan atau penyesuaian jika diperlukan.

## 5. Meminta ChatGPT Membuat Media Pembelajaran Berbasis Web

Setelah rancangan media pembelajaran selesai, langkah berikutnya adalah meminta ChatGPT membuat kode program yang dapat dijalankan melalui browser.

Guru dapat menggunakan prompt berikut:

**Contoh Prompt 2:**

> Berdasarkan rancangan media pembelajaran yang telah dibuat, sekarang buatkan media pembelajaran interaktif berbasis web menggunakan HTML, CSS, dan JavaScript.
>
> Ketentuan:
> 1. Seluruh kode program dibuat dalam satu file HTML.
> 2. Gunakan desain yang menarik, modern, dan responsif.
> 3. Sediakan halaman pembuka dan petunjuk penggunaan.
> 4. Tampilkan materi Sistem Tata Surya secara ringkas.
> 5. Buat 10 soal pilihan ganda.
> 6. Berikan penilaian otomatis setelah peserta didik menjawab soal.
> 7. Tampilkan skor akhir dan keterangan hasil evaluasi.
> 8. Pastikan seluruh tombol dan fitur dapat berfungsi dengan baik.
>
> Berikan kode program secara lengkap agar dapat langsung disimpan dan dijalankan melalui browser.

ChatGPT kemudian akan menghasilkan kode program sesuai instruksi tersebut.

Jika hasil yang diberikan belum sesuai harapan, guru dapat meminta ChatGPT memperbaiki tampilan, menambahkan fitur, atau memperbaiki kesalahan program.

**Catatan:** Kode yang dihasilkan ChatGPT tetap perlu diperiksa dan diuji. Jangan langsung menganggap seluruh fitur sudah berfungsi dengan benar.

## 6. Menyimpan dan Menjalankan Media Pembelajaran

Setelah ChatGPT menghasilkan kode HTML, langkah berikutnya adalah menyimpan kode tersebut menjadi sebuah file.

Caranya sebagai berikut:

1. Buka Visual Studio Code atau editor teks lainnya.
2. Buat file baru.
3. Salin seluruh kode HTML yang dihasilkan ChatGPT.
4. Tempelkan kode tersebut ke dalam file baru.
5. Simpan file dengan nama, misalnya `media-pembelajaran.html`.
6. Buka file tersebut menggunakan browser seperti Google Chrome atau Mozilla Firefox.

Jika tidak terdapat kesalahan pada kode program, media pembelajaran akan tampil di browser dan dapat langsung digunakan.

**Hal yang perlu diperhatikan:**

Media pembelajaran berbentuk satu file HTML dapat dijalankan secara lokal tanpa harus menggunakan hosting. Namun, jika kode menggunakan gambar, audio, atau pustaka dari internet, koneksi internet mungkin tetap diperlukan agar seluruh komponen dapat ditampilkan dengan baik.

## 7. Mengembangkan Media agar Lebih Menarik dan Interaktif

Setelah media pembelajaran berhasil dijalankan, guru dapat meminta ChatGPT mengembangkan berbagai fitur tambahan agar pengalaman belajar peserta didik menjadi lebih menarik.

Beberapa fitur yang dapat ditambahkan antara lain:

1. **Musik latar:** memberikan suasana belajar yang lebih menyenangkan.
2. **Animasi:** membuat tampilan materi menjadi lebih hidup.
3. **Timer:** membatasi waktu pengerjaan kuis.
4. **Umpan balik otomatis:** memberikan penjelasan setelah peserta didik menjawab soal.
5. **Tampilan responsif:** menyesuaikan tampilan media dengan ukuran layar komputer maupun telepon pintar.
6. **Leaderboard:** menampilkan peringkat peserta didik berdasarkan hasil kuis.

Guru dapat meminta ChatGPT menambahkan fitur tersebut secara bertahap agar perubahan lebih mudah diperiksa.

Perlu diperhatikan bahwa fitur seperti leaderboard, penyimpanan nilai bersama, dan pemantauan hasil belajar banyak peserta didik memerlukan penyimpanan data bersama, misalnya melalui server dan database. Fitur tersebut tidak cukup hanya mengandalkan satu file HTML yang dijalankan secara lokal.

Dengan pengembangan yang tepat, media pembelajaran dapat menjadi lebih interaktif dan sesuai dengan kebutuhan peserta didik.

## 8. Menguji Media Pembelajaran

Sebelum digunakan dalam kegiatan pembelajaran, media yang telah dibuat perlu diuji terlebih dahulu.

Pengujian bertujuan memastikan bahwa seluruh materi, soal, tombol, dan fitur berjalan sebagaimana mestinya.

Beberapa hal yang perlu diperiksa antara lain:

1. Apakah seluruh materi sudah sesuai dengan tujuan pembelajaran?
2. Apakah pertanyaan dan pilihan jawaban sudah benar?
3. Apakah kunci jawaban dan sistem penilaian berfungsi dengan tepat?
4. Apakah seluruh tombol dapat digunakan?
5. Apakah tampilan media sudah nyaman dilihat melalui komputer maupun telepon pintar?
6. Apakah musik, animasi, dan fitur tambahan lainnya berjalan dengan baik?

Guru juga perlu memeriksa kembali kebenaran materi dan jawaban yang dihasilkan oleh ChatGPT. AI dapat menghasilkan informasi yang keliru sehingga hasilnya tidak boleh langsung digunakan tanpa pemeriksaan.

Jika ditemukan kesalahan, guru dapat meminta ChatGPT melakukan perbaikan hingga media pembelajaran berjalan sesuai harapan.

## 9. Membagikan Media Pembelajaran kepada Siswa

Setelah media pembelajaran selesai dibuat dan diuji, guru dapat membagikannya kepada peserta didik.

Ada beberapa cara yang dapat dilakukan:

1. **Melalui file HTML:** guru dapat membagikan file media pembelajaran secara langsung kepada peserta didik melalui flashdisk, WhatsApp, atau Google Drive. Peserta didik kemudian mengunduh dan membuka file tersebut menggunakan browser.
2. **Melalui layanan hosting:** guru dapat mengunggah file HTML ke layanan hosting agar media dapat diakses melalui sebuah alamat website.
3. **Melalui blog atau website sekolah:** media pembelajaran dapat diintegrasikan ke dalam blog atau website sekolah sehingga peserta didik lebih mudah mengaksesnya.

Pemilihan cara membagikan media dapat disesuaikan dengan fasilitas dan kondisi jaringan internet yang tersedia.

Dengan demikian, media pembelajaran yang dibuat dengan bantuan ChatGPT tidak hanya dapat digunakan oleh guru secara pribadi, tetapi juga dapat dimanfaatkan oleh peserta didik dalam kegiatan belajar.

## 10. Tips Membuat Media Pembelajaran dengan ChatGPT

Agar proses pembuatan media pembelajaran berjalan lebih efektif, berikut beberapa tips yang dapat diterapkan oleh guru:

1. **Gunakan prompt yang jelas dan terperinci.** Semakin jelas instruksi yang diberikan, semakin mudah ChatGPT memahami kebutuhan guru.
2. **Kerjakan secara bertahap.** Mulailah dari menyusun konsep, membuat rancangan, menghasilkan kode, hingga menambahkan fitur.
3. **Jangan ragu meminta revisi.** Jika hasilnya belum sesuai, berikan instruksi tambahan agar ChatGPT melakukan perbaikan.
4. **Periksa kebenaran materi.** Pastikan seluruh informasi, soal, dan kunci jawaban sesuai dengan sumber pembelajaran yang dapat dipercaya.
5. **Sesuaikan dengan karakteristik peserta didik.** Gunakan bahasa, tampilan, dan tingkat kesulitan yang sesuai dengan jenjang pendidikan.
6. **Perhatikan keamanan dan privasi.** Hindari memasukkan nama lengkap, alamat, nomor telepon, atau data pribadi peserta didik ke dalam prompt.
7. **Lakukan pengujian sebelum digunakan.** Pastikan media dapat berjalan dengan baik pada perangkat yang akan digunakan peserta didik.

Guru tidak harus menjadi seorang programmer untuk mulai mengembangkan media pembelajaran berbasis teknologi. Dengan kreativitas, kemauan belajar, dan bantuan ChatGPT, proses tersebut dapat dilakukan secara bertahap.

## Penutup

Pemanfaatan kecerdasan buatan seperti ChatGPT memberikan peluang besar bagi guru untuk mengembangkan media pembelajaran yang lebih menarik, interaktif, dan inovatif.

Melalui langkah-langkah yang telah dijelaskan, guru dapat mulai membuat media pembelajaran berbasis web tanpa harus memiliki kemampuan pemrograman yang mendalam.

Meskipun demikian, teknologi AI tetap merupakan alat bantu. Kreativitas, pengetahuan, dan pertimbangan profesional guru tetap menjadi faktor utama dalam menentukan kualitas pembelajaran.

Dengan kemauan untuk terus belajar dan bereksperimen, guru dapat memanfaatkan teknologi AI untuk mengembangkan pembelajaran yang lebih menarik, interaktif, dan sesuai dengan kebutuhan peserta didik.
